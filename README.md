# Disparador de cron de TRIAD

Este repo NO tiene código de la app — solo existe para llamar cada 5 minutos
a `https://triadcol.com/api/cron/gestion`, porque el plan gratis de Vercel
solo deja correr su propio cron una vez al día. Así, las publicaciones
programadas de Instagram salen a la hora que se elija, no siempre a las 8am.
